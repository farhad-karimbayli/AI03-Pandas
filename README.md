## 🧠 Разбор логики каждого задания

### Задание 1: Данные о книгах
- **Цель:** Инициализация DataFrame, расчет агрегатов, фильтрация строк и сортировка.
- **Используемые методы Pandas:**
  - `pd.DataFrame(data)`: создание таблицы из словаря со списками.
  - `df['Цена'].mean()`: расчет среднего арифметического числового столбца.
  - `df[df['Год издания'] > 2015]`: фильтрация с использованием булевой маски.
  - `df.sort_values(by='Цена', ascending=True)`: сортировка по значению цены по возрастанию.

### Задание 2: Данные о заказах (CSV)
- **Цель:** Работа с внешними файлами, подсчет частот и экстремумов.
- **Используемые методы Pandas:**
  - `pd.read_csv('data/orders.csv')`: чтение структурированных данных из CSV.
  - `df.head(10)`: вывод первых 10 строк выборки.
  - `df['Клиент'].value_counts()`: самый эффективный способ подсчета количества заказов по каждому клиенту.
  - `df['Сумма'].max()` и `df['Сумма'].min()`: нахождение максимальной и минимальной стоимости.
  - `df['Сумма'].sum()`: расчет общей суммы заказов.
  - `df['Сумма'].idxmax()` / `idxmin()`: получение индексов записей с экстремальными значениями для вывода полной информации о заказе.

### Задание 3: Продукты питания
- **Цель:** Фильтрация по числовому критерию, группировка по категориям и сортировка по убыванию.
- **Используемые методы Pandas:**
  - `df[df['Калории'] > 300]`: нахождение высококалорийных продуктов.
  - `df.groupby('Категория')['Белки'].mean()`: группировка по полю `Категория` и вычисление среднего содержания белков для каждой группы (аналог SQL: `SELECT Категория, AVG(Белки) FROM Products GROUP BY Категория`).
  - `df.sort_values(by='Калории', ascending=False)`: сортировка от наибольшего к наименьшему.

### Задание 4: Сотрудники и проекты
- **Цель:** Двусторонняя агрегация матрицы рабочего времени и поиск максимального элемента.
- **Используемые методы Pandas:**
  - `df.groupby('Имя')['Часы'].sum()`: суммарные часы каждого сотрудника.
  - `df.groupby('Проект')['Часы'].sum()`: суммарная трудоемкость каждого проекта.
  - `hours_per_employee.idxmax()`: получение имени сотрудника, набравшего максимальное количество часов.

### Задание 5: Продажи билетов в кино
- **Цель:** Анализ региональных продаж и определение фильма-лидера.
- **Используемые методы Pandas:**
  - `df.groupby('Фильм')['Проданные билеты'].sum()`: суммарные продажи по каждому фильму во всех городах.
  - `df.groupby('Город')['Проданные билеты'].sum()`: суммарные продажи по каждому городу.
  - `sales_by_film.idxmax()`: выявление самого кассового фильма.
  - `sales_by_film.sort_values(ascending=False)`: ранжирование проката.
